Install and run

  1. Use 64-bit Windows with Microsoft Edge WebView2. Compare the installer hash with the checksum above before running it: Get-FileHash -Algorithm SHA256 .\MountAlpha-Binance-Setup.exe
  2. Open MountAlpha Flow after installation. Start with the simulated account; it does not need an exchange API key.
  3. Live trading starts paused. It requires device authorization, a configured Binance account and a separate manual start.

Common questions

Is this a Binance spot trading bot?
No. This edition is for Binance USDT perpetual futures, not spot trading or wallet management.
Do I need a GitHub account to download?
No GitHub account is needed to download. Live trading uses your separate Binance account and device authorization.
How do I update an installed copy?
Read the release notes before updating. Do not uninstall a live installation as a workaround for an update refusal.
How do I get help?
Use Support in the app. Include the version and issue, but never send API secrets, passwords or codes.

MountAlpha is independently developed and is not an official Binance product. Leveraged trading can cause substantial losses. Simulated results do not predict live returns.
