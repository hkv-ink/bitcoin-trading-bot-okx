MountAlpha 阿尔法峰 EasiCoin 版（分析大师）

面向 EasiCoin USDT 永续合约的 Windows 中文自动交易软件，支持比特币（BTC）和以太坊（ETH）。客户端提供模拟账户、独立实盘控制、持仓与订单记录，也保留分析大师的加密客服、公告及文件接收。

下载 Windows 安装包 发行说明 SHA-256 校验值

安装和升级

  1. 使用 64 位 Windows。运行安装包前，将 PowerShell 计算的哈希与上面的校验值对比： Get-FileHash -Algorithm SHA256 .\MountAlpha-EasiCoin-Setup.exe
  2. 已有分析大师文件传输版时，请选择安全维护时段，退出客户端及后台后直接覆盖安装。不要先卸载；覆盖升级保留 API 设置、账本、授权和本地客服数据。
  3. 安装后从「分析大师」进入。模拟无需交易所 API；实盘需要自己的 EasiCoin API、有效设备授权和手动启动。

常见问题

这个版本支持比特币和以太坊现货吗？
本版用于 EasiCoin USDT 永续合约，不是现货自动交易软件，也不是数字货币钱包。
下载需要 GitHub 账号吗？
公开安装包不用登录。交易所账号和软件授权与 GitHub 账号无关。
遇到安装或授权问题怎么办？
在客户端使用「联系授权 / 问题反馈」。说明版本和问题，请勿发送 API 密钥、密码或验证码。

MountAlpha 为独立软件，不是 EasiCoin 官方产品。杠杆交易可能造成重大损失，模拟结果不代表实盘收益。
