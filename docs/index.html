MountAlpha 阿尔法峰比特币自动交易软件

面向 OKX 欧易 USDT 永续合约的 Windows 自动交易软件，支持比特币（BTC）和以太坊（ETH）。客户端提供模拟账户、持仓与订单记录，以及独立的实盘控制。

币种欧易永续合约
比特币（BTC）BTC-USDT-SWAP

安装和首次运行

  1. 使用 64 位 Windows 和 Microsoft Edge WebView2。运行安装包前，用 PowerShell 计算哈希，并与上方的校验值比对： Get-FileHash -Algorithm SHA256 .\MountAlpha-OKX-Setup.exe
  2. 安装后打开「OKX 策略运行器 文件传输版」。建议先使用模拟账户，模拟不需要交易所 API 密钥。
  3. 实盘默认暂停，需要绑定 OKX 账户、完成设备授权，并由用户手动启动。

常见问题

这个版本支持欧易现货吗？
不支持。这个版本用于欧易 USDT 永续合约，不是现货自动交易软件或数字货币钱包。
下载需要 GitHub 账号吗？
不用登录即可下载。实盘所需的交易所账户、设备授权与 GitHub 账号无关。
遇到安装或授权问题怎么办？
在软件里使用「联系客服」。说明客户端版本和问题现象，不要发送 API 密钥、密码或验证码。

MountAlpha 为独立软件，不是 OKX 欧易官方产品。杠杆交易可能造成重大损失，模拟结果不代表实盘收益。
